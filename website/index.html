MalwareScope
Master's thesis

            
Malware analysis platform: a trained classifier gives the verdict, an LLM explains it, and an isolated Windows sandbox shows what the file really does. It refuses to run a sample it cannot watch, then exports findings to Splunk, Cortex XDR and STIX. Built with Omar Kharrat.

  • scikit-learn
  • KVM
  • Sysmon
  • FastAPI
